# CPP

Университетские работы по C++ за два семестра обучения в Казанском федеральном университете: около сотни небольших программ по алгоритмам, массивам и матрицам, обработке строк, динамическим структурам данных, ООП, шаблонам, STL и работе с файлами.

> **Примечание.** Репозиторий хранится как архив учебных работ. Названия папок и файлов — на русском, в том виде, в котором работы сдавались. Моя профессиональная специализация — фронтенд-разработка, актуальные проекты в [закреплённых репозиториях профиля](https://github.com/FatB0YY).

## Семестр 1 — `1-semester-C++`

Процедурный C++ и классические алгоритмические задачи.

| Папка | Содержимое |
| --- | --- |
| `CPP-1-EXAM-main` | Основной экзаменационный набор: ~40 пронумерованных задач, каждая — отдельная программа |
| `CPP-KR-1-main` | Задания контрольной работы |
| `app` | ~30 отдельных программ с лекций и самостоятельной практики |

Темы, покрытые задачами:

- **Теория чисел** — сумма делителей, НОД, проверка на простоту, простые числа в диапазоне, числа Фибоначчи, факториал, возведение в степень, число сочетаний
- **Массивы** — динамическое выделение памяти и ввод, сортировка, бинарный поиск, слияние двух отсортированных массивов, k-й максимум, два наибольших элемента, максимум по условию, циклический сдвиг, проверка монотонности и симметричности последовательности
- **Множества на массивах** — равенство, вхождение одного в другое, объединение, пересечение
- **Матрицы** — динамическое выделение памяти, суммы главной и побочной диагоналей, суммы выше и ниже диагонали, строка или столбец с максимальной суммой, поиск нулевой строки или столбца, перестановка строк и столбцов, транспонирование, сложение и умножение двух матриц n×n
- **Строки** — получение k-го слова, самое длинное слово, палиндромы, слова с совпадающими первой и последней буквой, обратный порядок слов, удаление пробелов
- **Прочее** — проверка правильности скобок, вычисление полинома, эксперименты с переполнением памяти

## Семестр 2 — `2-semester-C++`

Объектно-ориентированный C++, динамические структуры данных и стандартная библиотека.

| Папка | Содержимое |
| --- | --- |
| `ооп` | Классы, конструкторы и деструкторы, инкапсуляция, `this`, перегрузка операторов, умные указатели, класс вектора, класс с информацией о студенте |
| `перегрузка` | Задачи на перегрузку операторов |
| `стек и очереди` | Реализации стека и очереди |
| `шаблоны` | Шаблоны функций и классов |
| `файлы` | Запись и чтение массивов и матриц в текстовые и бинарные файлы |
| `ЭКЗАМЕН` | Экзаменационный набор — STL, динамические структуры данных (`ДСД`), шаблоны, конструктор копирования и оператор присваивания, а также прочие задачи |

## Сборка и запуск

Каждая задача — самостоятельный `.cpp` файл со своим `main`. Компилируется напрямую:

    g++ -std=c++17 "path/to/file.cpp" -o program
    ./program

Все программы консольные, часть из них читает или пишет `.txt` файлы, лежащие рядом с исходником.
